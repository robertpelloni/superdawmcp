# Changelog

## [1.0.0] - 2026-05-22
### Added
- Initial project structure for SuperDAW-Universal-MCP.
- Integrated 25+ open-source DAW-MCP submodules as architectural references.
- Go-based core daemon for MCP orchestration.
- `DAWDriver` interface for multi-DAW support.
- Ableton Live driver with OSC implementation.
- REAPER driver with HTTP/OSC implementation.
- VST scanning and parameter caching module.
- Comprehensive documentation: VISION, MEMORY, DEPLOY, IDEAS, ROADMAP, TODO.
- Multi-stage Makefile for build automation.
