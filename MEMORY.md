# Codebase Memory & Architectural Observations

- **Unified Dashboard Architecture**: The web console lives in `pkg/ux/dashboard/` and is served on port 8081. It avoids template variable collision by escaping `%` signs (`%%`).
- **Synchronous Plugin Querying**: In addition to asynchronous MCP bus dispatch (`/api/call`), the dashboard provides synchronous REST query endpoints (`/api/plugins?name=...&deep=true`) for instant parameter population.
- **Process Management**: Graceful server termination is exposed via `/api/quit`, triggering clean daemon teardown across HTTP, WebSocket, OSC, and TCP socket listeners.
- **Root Directory Cleanliness**: Do not leave runnable `main` package files at the repository root (`test_*.go`), as they break package builds (`go test ./...`). Auxiliary scratch scripts must be archived in `archive/`.
- **DAW Driver Completeness**: All drivers must implement every method on `daw.DAWDriver` (`SendCC`, `SetPluginParameter`, etc.) even if stubbed for uncooperative DAWs, avoiding duplicate declaration collisions.
- **Version Governance**: `VERSION.md` is the single source of truth for versioning (v3.22.0), read dynamically by both documentation and the Go binary at runtime.
- **Snapshot Banks & Continuous Morphing**: Managed across web Master Studio Console (`pkg/ux/dashboard/ui.go`), web mobile remote (`pkg/ux/dashboard/remote.go`), and React Native remote (`mobile/src/screens/PluginScreen.tsx`) using slots A, B, C, D and linear interpolation.
- **Parameter Lock Safeguards & Batch Engine**: Implemented in `pkg/vst/scanner.go` via `IsLocked` flag, `SetParamLock`, `GetParamLock`, and `BatchUpdateParams`. `BatchUpdateParams` guarantees atomic updates where locked parameters are strictly skipped and unlocked values are bounded to `[MinValue, MaxValue]`.
- **Parameter Tagging & Favorites Engine**: Implemented in `pkg/vst/scanner.go` via `IsFavorite` and `Tags []string`, with `SetParamFavorite`, `AddParamTag`, and `GetFavoriteParams`. Displayed with interactive star toggles and semantic badges in the Master Console and Mobile Remote.
- **Macro Modulation Links & Mapping Matrix**: Implemented in `pkg/vst/scanner.go` via `MacroAssignments map[string]float32`, `AssignParamMacro`, and `GetMacroParams`. Weighted macro modulation links are rendered as tactile badges (`✨ brighten (+100%)`, `🔥 warmth (+85%)`, `🥊 punch (-80%)`) in the Master Studio Console and Mobile Remote, with delta modulation scaling proportionally by assigned weights.
- **VST3 MIDI CC Mapping & Hardware Routing**: Implemented in `pkg/vst/scanner.go` via `MidiCC` field on `ParamMetadata`, `AssignParamMidiCC(pluginName, paramIndex, cc)`, and `GetParamByMidiCC(pluginName, cc)`. Standard continuous controllers (CC 7, 74, 71, 73, 75, 72, 1, 93, 91) are auto-mapped, rendered with cyan `🎛️ CC <number>` badges in the console and purple badges in mobile, and dynamically managed through `🎹 LEARN`.
- **Desktop System Tray Controller**: `scripts/superdaw_tray.py` inspects daemon port connectivity (8081, 12001, 12002) and triggers `/api/quit` for graceful background server termination.
